Add this interaction/animation upgrade to the previous prompt:

ADVANCED INTERACTIONS & ANIMATIONS

Make the website highly interactive and visually engaging while keeping the overall aesthetic premium, elegant and smooth.

The goal is for visitors to feel the interface responding to them, not simply scroll through static sections.

Use subtle, polished motion inspired by premium Apple-style websites and modern creative portfolios.

1. HERO — LIQUID GLASS MOTION

The hero should immediately feel interactive.

Background

Create several large blurred pastel gradient blobs behind the hero.

As the user moves the mouse:

Gradient blobs subtly follow the cursor

Different layers move at slightly different speeds

Create a soft 3D depth/parallax effect

Do not make the movement aggressive.

Hero text

When the page loads:

Small freelancer badge fades in

Main heading rises upward with blur-to-sharp animation

Description follows slightly afterward

CTA buttons appear with a subtle scale + fade

Floating portfolio previews appear one by one

Use staggered timing rather than everything appearing simultaneously.

2. FLOATING PORTFOLIO PREVIEWS

The hero portfolio mockups should feel like floating glass objects.

Each preview card should have:

Slight floating animation

Very subtle rotation

Independent movement

Soft shadow

Glass reflection

Tiny parallax movement

When the cursor moves around the hero, the cards should respond with a subtle 3D tilt.

Example:

Cursor moves right → cards gently rotate toward the cursor.

Cursor moves left → cards follow in the opposite direction.

Keep the effect elegant and limited.

3. SERVICE CARDS — 3D TILT HOVER

The three service cards should NOT be static.

Each card should have an interactive 3D tilt effect.

When the cursor enters:

Card slightly lifts

Card rotates toward cursor position

Glass becomes slightly brighter

Border glow increases

Shadow becomes deeper

Internal image/content shifts slightly

A subtle light reflection moves across the glass surface

Use a perspective effect similar to:

perspective + rotateX + rotateY

Keep the maximum rotation subtle, approximately 4–7 degrees.

When the cursor leaves:

The card smoothly returns to its original position.

Use spring-like easing rather than an instant reset.

4. SERVICE CARD MAGNETIC EFFECT

Make the CTA inside each service card slightly magnetic.

When the cursor approaches:

Button gently moves toward the cursor

Button scales slightly

Arrow shifts forward

When the cursor leaves:

It smoothly returns to its original position.

Keep this subtle.

5. SERVICE CARD HOVER REVEAL

Each service card should reveal additional information on hover.

Normal state:

Invitation Design

Short description.

On hover:

The card subtly expands/reveals:

Wedding · Birthday · Engagement · Baby Shower · Events

and a:

Explore →

interaction.

The reveal should feel smooth rather than abrupt.

6. SCROLL-BASED SECTION REVEALS

Every major section should animate into view when the user scrolls.

Do NOT animate everything with the same effect.

Use different but consistent reveal styles.

For example:

Services

Cards enter one after another from slightly different vertical positions.

Portfolio

Images reveal using a soft clip-path/mask animation.

Process

Steps appear sequentially as the user scrolls.

About

Image and text enter from opposite directions.

Final CTA

Glass panel slowly scales from approximately 95% → 100%.

Animations should trigger only when the section enters the viewport.

Use smooth easing.

7. SCROLL PARALLAX

Introduce multiple layers of movement while scrolling.

For example:

Background gradient:
slow movement

Glass decorative shapes:
medium movement

Portfolio images:
slightly faster movement

Text:
very subtle movement

This should create a sense of depth.

Do not overdo the parallax.

8. SCROLL PROGRESS EFFECT

Add a very thin elegant progress indicator at the top of the page.

As the user scrolls:

0% → 100%

The indicator should smoothly progress across the top.

Use a subtle gradient matching:

Blush Rose → Champagne → Dusty Lilac.

9. NAVIGATION SCROLL EFFECT

Initially:

Navigation is almost transparent.

When the user starts scrolling:

Navigation becomes a compact glass pill/bar

Background becomes slightly more opaque

Backdrop blur increases

Soft border appears

Shadow becomes visible

The transition should happen smoothly rather than instantly.

10. PORTFOLIO CARD INTERACTIONS

The portfolio gallery should be one of the most interactive parts of the website.

When hovering over a project:

Before hover

Normal image preview.

On hover

Image gently zooms

Card slightly tilts

Glass overlay appears

Project category appears

Project title fades upward

"View Project →" appears

Cursor interaction becomes more noticeable

Example:

Wedding Invitation

Invitation Design

View Project →

11. PORTFOLIO IMAGE REVEAL

When portfolio items enter the viewport:

Do not simply fade them in.

Use a modern reveal animation:

Image container appears

Mask/clip-path opens

Image smoothly reveals

Text appears afterward

Each portfolio item should have a slightly different delay.

This should feel like a professional design portfolio.

12. IMAGE HOVER DEPTH

Portfolio images should respond to cursor movement.

When the cursor moves:

Image subtly moves in the opposite direction

Background stays relatively stable

Creates a small depth/parallax effect

This should be very subtle.

13. PROCESS SECTION — SCROLL STORYTELLING

Make the process section more interactive.

As the user scrolls:

01 → 02 → 03 → 04

The current step becomes visually highlighted.

The connecting line gradually fills as the user progresses.

Each step can slightly move/scale into focus.

This creates a feeling of moving through a journey rather than simply reading four cards.

14. ABOUT SECTION PARALLAX

Use a split layout.

Left:
Profile/image glass frame.

Right:
About text.

As the user scrolls:

Image moves slightly slower

Text moves normally

Small decorative glass elements move at different speeds

Create subtle depth.

15. FINAL CTA INTERACTION

The final CTA should feel like the visual climax of the page.

Create a large glass panel.

As the user approaches it:

Panel softly scales from 95% to 100%

Background gradient slowly shifts

Decorative glass shapes float

Border glow becomes slightly stronger

The CTA button should have a premium hover interaction:

Normal:

Start a Project →

Hover:

Let's Create →

The arrow should smoothly move forward.

16. BUTTON MICRO-INTERACTIONS

Every button throughout the website should have a polished interaction.

On hover:

Slight scale: approximately 1.03

Background transitions smoothly

Arrow moves a few pixels

Soft glow appears

On click:

Very subtle compression effect

Then return to normal

Avoid exaggerated button animations.

17. CURSOR INTERACTION

On desktop, create a subtle custom cursor system.

Normal cursor:
Small elegant dot.

When hovering over:

Buttons → cursor expands slightly

Portfolio images → cursor becomes a circular "View" indicator

Links → subtle expansion

Interactive cards → soft glow

Do not use a huge distracting custom cursor.

On mobile, disable custom cursor effects.

18. SECTION TRANSITIONS

Do not make each section look completely disconnected.

Create visual continuity between sections using:

Blurred gradient shapes

Floating glass elements

Soft color transitions

Overlapping cards

Large curved/organic background shapes

Subtle parallax

The page should feel like one continuous liquid-glass environment.

19. PAGE LOAD EXPERIENCE

Create a short premium loading sequence.

Show:

[YOUR BRAND NAME]

with a soft glass/gradient animation.

Then:

Logo/name fades

Background smoothly appears

Hero content reveals

Page becomes interactive

Keep the loading experience short.

Do not make users wait unnecessarily.

20. PERFORMANCE RULE

Although the website should contain impressive animations, prioritize smooth performance.

Animations must feel:

Smooth → Responsive → Lightweight → Premium

Avoid:

Excessive particle effects

Heavy 3D scenes

Constant large-scale animations

Excessive blur that affects performance

Animations that interfere with reading

Use GPU-friendly transforms where possible.

Respect prefers-reduced-motion and provide a reduced-animation experience for users who have motion sensitivity.

OVERALL MOTION LANGUAGE

The animation personality should be:

Soft + Fluid + Interactive + Premium + Playful + Elegant

Think:

Liquid glass + editorial portfolio + Apple-style motion + creative studio

NOT:

Gaming website + flashy agency template + excessive animation.

Every animation should have a purpose.

The visitor should discover small interactions naturally while exploring the website.
